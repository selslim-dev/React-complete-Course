# React Essentials

This project contains the code and exercises completed during the **React Essentials** section of Maximilian Schwarzmüller's React course on Udemy.

## 📚 Topics Covered

- React Components
- JSX (JavaScript XML)
- Props
- State Management
- Event Handling
- Conditional Rendering
- Rendering Lists
- Component Composition
- Dynamic UI Updates

## 🎯 Learning Objectives

The goal of this section was to understand the fundamental concepts of React and build reusable, interactive user interfaces by learning how React components communicate and manage data.

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- JSX
- HTML5
- CSS3
- Vite

## 📁 Project Structure

```
src/
├── assets/
├── components/
├── App.jsx
├── index.css
└── main.jsx
```

## 🚀 Getting Started

Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd react-essentials
npm install
npm run dev
```
