# React Essentials — Practice Project

Practice project from **Section 5: React Essentials - Practice Project** of Maximilian Schwarzmüller's React course on Udemy.

**Progress:** 8/8 lessons complete · 54min

## Concepts Covered

- Building and structuring a `Header` component
- Getting started with a user input component
- Handling events & two-way binding
- Lifting state up between components
- Computing derived values & properly handling number inputs
- Outputting results dynamically in a list
- Conditional rendering of content

## Tech Stack

`React` `JavaScript` `Vite`

## Notes

This project reinforces core state management patterns (lifting state, controlled inputs) and derived/computed values before moving into styling.
