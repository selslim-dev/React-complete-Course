# Debugging React Apps

Practice project from **Section 7: Debugging React Apps** of Maximilian Schwarzmüller's React course on Udemy.

**Progress:** 7/7 lessons complete · 29min

## Concepts Covered

- Understanding React error messages
- Using the browser debugger & setting breakpoints
- Understanding React's "Strict Mode"
- Using the React DevTools (browser extension)
- Fixing intentionally broken code (Exercise 20: Fix Errors)

## Tech Stack

`React` `JavaScript` `Vite`

## Notes

This project focuses on developer tooling rather than new React features — learning to read error messages, step through code with breakpoints, and use React DevTools to inspect component state and props.
