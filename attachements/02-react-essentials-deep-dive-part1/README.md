# React Essentials Deep Dive — Part 1

A hands-on deep dive into more advanced React fundamentals, building on the basics of components, JSX, and props.

## Topics Covered

- **JSX Alternatives** — Writing React elements without JSX using `React.createElement()`
- **Fragments** — Grouping elements without adding extra DOM nodes
- **Splitting Components** — When and how to split components by feature and by state
- **Forwarding Props** — Passing props down to inner/wrapped elements correctly
- **Multiple JSX Slots** — Supporting more than one "content area" in a component (e.g. `children` + custom props)
- **Dynamic Component Types** — Setting which element/component to render dynamically via props
- **Default Prop Values** — Providing fallback values for props using default parameters
- **Flexible, Reusable Components** — Building components (like a custom `Button`) that adapt based on props while forwarding all standard attributes

## Coding Exercises

- Using Fragments
- Forwarding Props
- Creating Flexible Components
